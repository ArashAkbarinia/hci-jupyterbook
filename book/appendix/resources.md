# Resources

Curated external material. Add to it as we go and prefer open or free sources for students.

## Textbooks and classics
- Norman, *The Design of Everyday Things* — the essential first read.
- Dix, Finlay, Abowd, Beale, *Human–Computer Interaction* — comprehensive standard text (older; use for foundations).
- Preece, Rogers, Sharp, *Interaction Design: Beyond Human–Computer Interaction*.
- MacKenzie, *Human–Computer Interaction: An Empirical Research Perspective* — experiments and Fitts' law.
- Buxton, *Sketching User Experiences*.
- Wolpaw & Wolpaw (eds.), *Brain–Computer Interfaces: Principles and Practice*.
- Kandel et al., *Principles of Neural Science* — neuroscience reference.

## Free online
- Interaction Design Foundation (free articles): https://www.interaction-design.org
- Nielsen Norman Group articles: https://www.nngroup.com/articles/
- Google PAIR *People + AI Guidebook*: https://pair.withgoogle.com/guidebook
- W3C Web Content Accessibility Guidelines (WCAG): https://www.w3.org/WAI/standards-guidelines/wcag/
- ACM CHI conference proceedings (digital library; many open-access): https://dl.acm.org/conference/chi

## Courses
- Scott Klemmer, *Human-Centered Design* (UC San Diego / Coursera)
- MIT 6.831 / 6.813 *User Interface Design and Implementation* (OpenCourseWare)

## BCI / neuro tools and datasets
- MNE-Python (EEG/MEG analysis): https://mne.tools
- MOABB (benchmarks for BCI algorithms): https://github.com/NeuroTechX/moabb
- BNCI Horizon 2020 datasets: http://bnci-horizon-2020.eu/database/data-sets
- OpenBCI (hardware, community): https://openbci.com
- NeuroTechX community: https://neurotechx.com
- Berlin BCI Competition datasets

## Tools for prototyping
- Figma, Penpot (open source) for UI prototypes
- p5.js / Processing for quick interactive sketches
- Python: `pynput`, `mediapipe` (gesture and gaze demos)
