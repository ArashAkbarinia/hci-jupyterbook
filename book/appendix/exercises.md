## Types of exercise

| Type | Purpose | Example |
|---|---|---|
| Observe | Notice interaction in the world | Chapter 1: one-day inventory |
| Analyse | Apply a framework | Heuristic evaluation of an app |
| Measure | Collect data | Fitts' law pointing experiment |
| Build | Make a prototype | Paper prototype, Wizard-of-Oz voice assistant |
| Code | Work with data | EEG motor-imagery classifier |
| Debate | Practise reasoning on ethics | Should healthy people receive implants? |

## Course project ideas

1. **Redesign a "too complicated" device** with at most three controls, then test it with five users.
2. **Modality comparison study**: voice vs. keyboard vs. touch for one task; within-subject, ≥ 12 participants.
3. **Accessibility audit** of a university service, with fixes proposed.
4. **Human–AI interaction critique**: pick an AI feature and evaluate it against the Amershi guidelines.
5. **BCI mini-project** (code): decode motor imagery from an open dataset and report accuracy honestly.
6. **Speculative design**: a "day in 2050" scenario with a technical and ethical annotation.
