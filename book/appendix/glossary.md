# Glossary

```{glossary}
Affordance
  A property of an object that suggests how it can be used.

BCI (Brain–Computer Interface)
  A system that translates brain activity into commands for a computer or device.

BMI (Brain–Machine Interface)
  Often used interchangeably with BCI; sometimes emphasises control of machines such as prostheses.

Fidelity
  How faithfully information is preserved when stored or passed on.

Interaction
  The loop in which a human perceives, decides and acts, and a computer senses, computes and responds.

Modality
  A channel (such as speech, touch, gaze) through which information is exchanged.

Signifier
  A perceivable cue that tells you where an action should take place.
```
