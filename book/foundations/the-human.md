```{admonition} Learning objectives
After this chapter you should be able to:
- describe how vision, hearing, touch (plus proprioception, balance) limit and shape interface design;
- explain attention, working memory and long-term memory, and their consequences for interfaces;
- describe human motor control and reaction time and why they bound input speed;
```

## Planned sections

1. Perception: vision (colour, acuity, motion), audition, somatosensation, smell/taste (why they are rare in interfaces)
2. Beyond five senses: proprioception, vestibular sense, thermoception, nociception
3. Attention and multitasking; change blindness; notifications as attention thieves
4. Memory: working memory limits (and the myth of 7±2), recognition vs recall
5. Motor control: reaction times, speed–accuracy trade-off (leads into Fitts' law)
6. Individual differences, ageing, disability: the 'average user' does not exist
7. Mental models and the gulfs of execution and evaluation

## Exercises

1. Run a reaction-time test on yourself with a visual and an auditory stimulus. Explain the difference.
2. Find an interface that overloads working memory. Redesign it to rely on recognition instead of recall.
3. Simulate colour-vision deficiency on a website you use. What breaks?
